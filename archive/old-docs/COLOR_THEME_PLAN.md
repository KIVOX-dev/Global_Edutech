## 2. New Color Theme (Proposed)

| Role                    | Color Name     | HEX Code  | Usage                                           |
|-------------------------|---------------|-----------|-------------------------------------------------|
| Brand Primary           | Soft Teal     | #1BA39C   | Logo accents, headings, icons, tabs             |
| Accent/CTA Color        | Coral Pink    | #FF6B6B   | Primary CTA buttons (“Book Now”)                |
| Secondary Highlight     | Pale Yellow   | #FFE082   | Section accents, badges, button hover           |
| Base Background         | White         | #FFFFFF   | Main content background, cards                  |
| Alternate Section BG    | Mint Mist     | #E0F7FA   | Used to separate long scroll sections           |
| Body Text/Headings      | Navy Gray     | #37474F   | Professional, soft navy gray                    |
| Light Text on BG        | White         | #FFFFFF   | For buttons or dark backgrounds                 |

**Font System:**  
- Headings: Poppins  
- Body: Open Sans  
- Button Text: Poppins Bold (Uppercase)
